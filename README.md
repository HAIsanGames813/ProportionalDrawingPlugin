# 比率描画
制作者:HAIsan

## 概要
描画位置・拡大率を解像度に対する比率（％）で設定できるようにするプラグインです。

## インストール方法
[ここからダウンロード](https://github.com/HAIsanGames813/ProportionalDrawingPlugin/releases/latest)

## 使用方法
映像エフェクトの「描画」タブに追加される以下のエフェクトを使用してください。

- **描画位置（比率）**：描画位置を解像度に対する比率（％）で設定できます。
- **拡大率（比率）**：拡大率を解像度に対する比率（％）で設定できます。

# Proportional Drawing
Author: HAIsan

## Overview
A plugin that allows you to set the drawing position and scale as percentages relative to the video resolution.

## Installation
[Download here](https://github.com/HAIsanGames813/ProportionalDrawingPlugin/releases/latest)

## How to Use
The following effects will be added to the **Drawing** tab of Video Effects:

- **Drawing Position (Ratio)**: Sets the drawing position as a percentage relative to the video resolution.
- **Scale (Ratio)**: Sets the scale as a percentage relative to the video resolution.
