# ProportionalDrawingPlugin

YMM4用の「拡大率(比率)」「描画位置(比率)」映像エフェクトです。

## 多言語対応

`Texts.csv` に日本語、英語、中国語（簡体字・繁体字）、韓国語、スペイン語、アラビア語、インドネシア語を定義しています。YukkuriMovieMaker.GeneratorのソースジェネレーターがCSVからresxとローカライザーを生成します。生成された言語別 `ProportionalDrawingPlugin.resources.dll` はビルド後に本体DLLと一緒にYMM4のプラグインフォルダへコピーされます。

Generatorはソリューション内の `YukkuriMovieMaker.Generator` プロジェクトとして含めています。プロジェクトは[公開リポジトリ](https://github.com/manju-summoner/YukkuriMovieMaker.Generator)の実装に基づきます。

## 実装内容

- YMM4の `VideoEffectBase` / `IVideoEffectProcessor` と `DrawDescription` を使用します。
- 数値はYMM4の `AnimationSlider` として定義し、キーフレーム値を各フレームで評価します。
- プロジェクト寸法は `EffectDescription.ScreenSize`、拡大率の基準画像寸法は入力画像の `GetImageLocalBounds` から取得します。
- 比率拡大率は基準方向に合わせて画像を画面の高さまたは幅にフィットさせ、全体・縦・横の各パーセント値を100で割って既存Zoomへ乗算します。
- 描画位置は画面中央原点の `Draw` 座標へ相対移動量を加算します。X/Yは中心が0%、画面端が±100%です。Zは%表記の値を画面寸法で換算せず、既存Z座標へ加算します。全数値パラメーターの値域は±10億です。
- 拡大率の倍率スライダー初期範囲は-100〜100%です。
- 基準方向はYMM4のプロパティ変更通知を行うため、選択切り替えがエフェクト再評価の通知対象になります。
- AviUtl出力用の変換には対応しません。

## ビルドと配置

通常のビルドはDLLを `bin` に生成します。YMM4へのコピーは既定で無効です。配置する場合は `DeployToYMM4=true` を指定してビルドしてください。

## 確認状況と制約

- ローカルのYMM4 DLLを参照してコンパイル確認済みです。
- YMM4上でのプレビュー、プロジェクト保存・再読み込み、解像度別の実動作は未確認です。
- 拡大率のフィット計算はYMM4がエフェクトへ渡す入力画像の境界に依存します。先行する画像変換エフェクトが境界を変える場合、基準寸法にも影響します。
- Zの「画面高さを100%とする」換算はユーザー向け仕様を満たすための実装上の定義です。YMM4の3Dカメラ上での視覚的な距離・奥行きは、プレビューでの確認が必要です。
- `DrawDescription` と画像境界APIはローカルYMM4バイナリで確認しました。内部の座標合成やエフェクト順序の細部はYMM4更新で変わる可能性があります。
